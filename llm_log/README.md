Файли `t2c-v1_*.json` / `t2c-v2_*.json` створює `t2c_pipeline.py` (дата, модель, temperature=0, seed=n/a, версія підказки, питання, сирий вихід, finish_reason, api_error, human_decision). Ключів API в логах немає.
Діалог із Claude (підготовка схеми, скриптів і документів) експортуйте вручну в `claude_session.md`.
