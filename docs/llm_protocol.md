## Обмеження чесності
- Синтетичні дані (≈80% графа) додано для виконання вимоги ≥100 вузлів/≥200 зв'язків; позначені `synthetic=true`.
- Значення PageRank/Louvain/Cypher у `docs/*.md`, поки не виконано `run_*.py`, — еталонні, а не з Neo4j.
- Студент відповідає за кожне твердження й має вміти пояснити/змінити будь-який запит під час захисту.
