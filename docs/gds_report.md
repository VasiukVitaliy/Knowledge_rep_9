# Аналіз графа та продуктивність (Результат 4)

> **Статус.** Числа нижче — **еталонний розрахунок** `reference.py` (формула PageRank із GDS: d = 0.85, ≤ 20 ітерацій, ненормалізований; Louvain — networkx, seed 42). Він потрібен для звірки й **не є виводом GDS**. Реальний вивід — `python run_gds.py` → `docs/gds_results_auto.md`. PageRank має збігтися майже повністю (той самий алгоритм); номери та склад спільнот Louvain можуть відрізнятися (стохастичний алгоритм, інша реалізація) — тоді в звіт беріть значення з GDS.

## 4. Інтерпретація для предметної області

(1) Найвищі значення PageRank мають перехрестя INT_LV_12, INT_LV_21 та INT_LV_07 — це реальні вузли з ЛР 7, до яких сходяться сегменти SEC_ST_03/07/11 і більшість маршрутів; у транспортній мережі це «хаби», збій яких зачіпає найбільше зв'язаних сутностей. (2) Для управління знаннями це підказка, які об'єкти потрібно підтримувати найретельніше: помилка або застарілий факт у хабі поширюється на багато сусідів, тому такі вузли мають мати найвищий confidence і регулярну верифікацію. (3) Сегменти SEC_ST_03, SEC_ST_07 і SEC_ST_11 також у топі, бо на них сходяться маршрути, події та датчики. (4) Louvain розбив граф на кілька спільнот: частина відповідає районам мережі (перехрестя + сегменти + світлофори), частина — функціональним групам (водії та їхні авто, ланцюжки процесів збору/аналізу/планування). (5) Це корисно для модульності знань: спільноти можна верифікувати, версіонувати й запитувати окремо, а зв'язки між спільнотами (міжспільнотні ребра) — це місця, де помилка у знаннях найлегше «перетікає» між підсистемами. (6) Обмеження: близько 80% даних синтетичні (180 із 227 вузлів, 388 із 486 зв’язків) (генератор із seed 42), тому значення ранжування відображають структуру згенерованого графа, а не реальний трафік Львова; висновки слід трактувати як демонстрацію методу.

## 6. Збережені властивості

Після `run_gds.py` кожен вузол має `pagerank` (float) і `community` (int). Перевірка: `MATCH (n) RETURN count(n), count(n.pagerank), count(n.community)` — усі три числа мають дорівнювати 227 (скрипт виводить це в розділі «Перевірка збереження властивостей»).
